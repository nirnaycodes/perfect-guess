# Guess the Number Game

A simple command-line number guessing game written in Python.

## How it works
- The computer picks a random number between 1 and 100.
- You guess a number, and the game tells you if your guess is too high or too low.
- Keep guessing until you get it right.
- After a correct guess, you can press Enter to play again or type `EXIT` to quit.

## How to run
```bash
python guess_game.py
```
